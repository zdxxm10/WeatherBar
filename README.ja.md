# WeatherBar

Windows の従来型タスクバーに、小さな天気表示。

[简体中文](README.md) | [English](README.en.md) | **日本語**

**現在のバージョン：1.1** · [正式リリース](https://github.com/zdxxm10/WeatherBar/releases/tag/v1.1) · [WeatherBar.exe をダウンロード](https://github.com/zdxxm10/WeatherBar/releases/download/v1.1/WeatherBar.exe)

## インストール

[Releases](https://github.com/zdxxm10/WeatherBar/releases/latest) から `WeatherBar.exe` をダウンロードし、書き込み可能な専用フォルダーで実行します。DLL とアイコンは内蔵しています。Windows のツールバー表示確認で許可するか、タスクバーの「ツールバー」から WeatherBar を選びます。現在のユーザーの登録と自動起動を設定します。

公開版は x64 Windows 10 の従来型タスクバー向けです。Windows 11 標準の新しいタスクバーは DeskBand に非対応です。その他の従来型タスクバー実装と32ビット環境でのインストールは未検証です。

リリースページでは EXE のみをダウンロードしてください。DLL・アイコン・ライセンスを内蔵しています。SHA-256 はリリースノートに記載し、検証用・ライセンス用 TXT の追加ダウンロードは不要です。ソースのライセンスは末尾をご覧ください。

## 設定

天気バーを右クリックして基本設定を開きます。先頭に言語と地点検索を配置し、カスタムURLは地点のカスタム設定で編集します。全方式で応答の時区とUTC偏差を自動取得し、手動入力は不要です。

外観と言語はすぐにプレビューへ反映します。色ボタンでパレットを開き、色見本・RGB スライダー・数値で選択できます。他の場所をクリックすると閉じます。URL は行幅で折り返す3行の欄です。初期幅は実際のフォントとDPIで中国語・英語・日本語を測定し、すべてを2列に収める最小幅です。列切替の基準も共通で、言語を切り替えても列数は変わりません。1列の最小幅は別に計算します。小さな画面ではスクロールできます。内容だけをスクロールし、下部の操作バーは固定します。ページ・候補一覧・URL欄の標準スクロールバーは必要な場合だけ表示し、標準の矢印は残します。

**保存**で設定を書き込み、**キャンセル**または閉じる操作で元の設定と予報キャッシュへ戻します。**外観を初期化**は地点・時差・言語を変更しません。入力途中の無効な URL は、外観プレビューを妨げません。検索・適用を明示したときだけ地点のリクエストを行います。

言語は簡体字中国語・英語・日本語です。既定ではシステムに従い、中国語の各地域は簡体字、日本語は日本語、その他は英語です。インストールと削除は設定言語と独立してシステム言語に従います。

予報は現地の0/6/12/18時に、既定15分のずらし時間を加えて更新します（`StaggerSeconds`、0–1800秒）。ツールチップは既定で有効で、明日・明後日の天気と最終更新時刻だけを選択します。データ状態とその他の項目は既定で無効です。更新時刻と状態は独立した項目です。全体を無効にしても選択を保持し、全項目が無効なら空の表示を出しません。保存済みの選択は保持し、欠けた項目にだけ既定値を使います。文字の実測幅に応じて1行に最大2項目を配置し、欠損値は `--` と表示します。変更は即時プレビューされ、キャンセルで元に戻ります。追加データは既存のリクエストと更新周期を共用し、風速は m/s です。更新確認は手動のみで、自動ダウンロードや自動インストールはありません。API が失敗した場合は、このリポジトリの公式最新リリースへのリダイレクトからバージョンを確認します。失敗時は HTTP または WinHTTP コードを表示します。

## 更新と削除

設定を保持して削除 → エクスプローラーの再起動を待つ → 同じフォルダーの EXE を置換 → 再実行します。カスタム SVG は保持し、不足分だけ追加します。旧名の設定も元ファイルを残して移行します。旧版から初めて更新する前は XML と icons をバックアップし、旧 EXE で先に削除してください。

通常の削除は設定・バックアップ・ログ・アイコン・EXE を保持し、停止した DLL・登録・自動起動を削除します。完全削除は設定と icons も削除し、終了後に Windows 標準 PowerShell で EXE と空フォルダーを削除します。無関係なファイルやディレクトリジャンクションの参照先は保持します。PowerShell が組織のポリシーで禁止されている場合、EXE の手動削除が必要になることがあります。エクスプローラーの再起動でフォルダー画面が閉じるため、先に作業を保存してください。

## 1.1 今後の天気ツールチップ

「明日の天気」と「明後日の天気」は独立したスイッチで、日付・天気・最低気温 / 最高気温をまとめて表示します。新規設定では両方オンです。設定形式3より古い設定の一度だけの移行で、従来の最高・最低気温のツールチップ設定がオンなら両日オン、明示的にオフなら両日オフ、未設定なら現在の既定値を使います。新形式の個別選択は保持し、移行時に追加のバックアップは作成せず、アトミックな保存が失敗した場合は元の設定を保持します。タスクバーの今日の最高・最低気温は変わりません。

天気は Open-Meteo の daily weather_code（その日の最も激しい現象）を直接変換した単一の要約で、天気の推移を表しません。霧雨とにわか雨は雨、着氷性の霧雨は着氷性の雨、雪粒とにわか雪は雪、ひょうを伴う雷雨は雷雨にまとめ、強度を区別しません。不明・欠損コードは「天気不明」です。設定地点の現地日付で今日・明日・明後日を照合し、欠損気温は個別に `--` を表示します。他の日付から補完せず、カスタム応答の日数不足も欠損のまま表示します。

各日付は1行を優先し、常に最低気温 / 最高気温の順です。例：`明日：部分的に曇り 13℃ / 22℃`。実際のフォント幅を測定し、幅が足りなければ日付と内容を2行に分けます。両日の間に空行を入れません。既存のリクエスト・キャッシュ・失敗状態・更新間隔を使います。

### 更新時刻・状態・国の絞り込み

最終更新時刻は有効な天気を取得して採用した実際の時点です。失敗、古い応答、再描画、言語変更では更新しません。表示時にPCの現在のシステム現地時刻へ変換し、時区名やUTC偏差は付けません。記録がなければ「未更新」です。日本時区のPCでは北京の天気でも更新時刻は日本時間です。天気の現在時刻、今日・明日・明後日、日の出・日の入り、更新予定は引き続き地点の時区を使います。

データ状態は選択した場合だけ表示します。優先順位は設定保護、地点未選択、更新中、天気未取得、古い予報、更新失敗でキャッシュ使用、正常です。無効でも既存の操作エラー表示は残し、無効な行の空白や区切りは残しません。

国・地域、地点、検索は同じ行で、地点入力に残り幅を配分します。順序は全言語で固定：指定なし；中国、中国香港、中国マカオ、中国台湾；日本、韓国、シンガポール、マレーシア、タイ、インドネシア、フィリピン、ベトナム、インド；イギリス、フランス、ドイツ、イタリア、スペイン、ロシア；アメリカ、カナダ、メキシコ、ブラジル；オーストラリア、ニュージーランド、南アフリカ、アラブ首長国連邦。未掲載の国はフィルターを送らない「指定なし」で検索できます。選択は番号でなくコードで保存します。HK/MO/TWの表示名だけ翻訳し、リクエストのコードをCNに変えません。新しい検索地点は名称・国コード・行政区を分けて保存し、復元や言語変更時に表示を組み立てます。コード不明の旧自由文は保持し、文字列を無条件に置換しません。

## 設定ウィンドウの配置

ネイティブのカードで設定を分類します。基本設定は全幅、十分な幅では左に表示と外観・間隔、右にツールチップ・アプリ情報と更新を順に配置します。表示/ツールチップ、間隔/アプリ情報の2行とし、各行は必要な高さの大きい方に合わせ上下をそろえます。狭い場合は基本設定・表示・間隔・ツールチップ・アプリ情報の1列になります。列数は3言語共通の実測幅、コントロール幅は実際の文字とDPIで決め、主文字を縮小しません。国・地域の幅は3言語で最長の選択肢に合わせ、言語欄と左端をそろえ、地点入力へ残り幅を配分します。

既定幅は、両列の内容・カード内余白・列間隔・外側余白・スクロールバー・標準枠と基本設定の検索/状態行を完全に収める最小幅です。実際のフォント・DPIで3言語を個別に測り、その最大値を初期幅と列切替の共通基準に使います。1列の最小幅は別に計算します。作業領域が不足する場合だけ1列で開きます。

アプリ情報にはバージョン、更新確認、リリースページ、結果を残します。出典はコンパクトな文字リンクで、従来のOpen-Meteo・GeoNames・ライセンス表示へアクセスできます。検索状態の表示元は1つだけで、境界や文字が変わるとそのコントロール全体だけを再描画し、古い文字を消して中央揃えの1行で表示します。

タイトルバーは閉じるだけで、枠でサイズを変更できます。外観を初期化・保存・キャンセルは下部に固定し、その上の内容だけをスクロールします。小さい画面、高DPI、地点のカスタム設定の展開でも内容にアクセスできます。候補リストと適用行は常設で、検索状態で大きく配置が変わりません。入力中の内容、フォーカス復帰、プレビュー・保存・キャンセルの動作は保持します。

ツールチップ全体のチェックボックスは、文字を残してカード見出しの右側に置きます。1列では各カードの自然な高さを使います。言語と国・地域の欄は、3言語の全項目を実測した共通の最小幅で左端をそろえ、標準の矢印/スクロールバーの幅は一度だけ加算します。国の一覧は全項目の表示を優先し、内容領域と画面の作業領域に収まらない場合はスクロール、必要に応じて上に開きます。ウィンドウの移動・サイズ変更やページスクロール時は一覧を閉じ、再度開くと位置を計算し直します。下部の固定操作バーには重ねません。

## 初回起動と地点設定

設定ファイルがない新規利用時だけ、現在気温・アイコン・最高/最低気温・2種類の間隔の6項目を既存の「大」にします。保存済みの値と既存ファイルの欠損項目の従来値は保持します。外観を初期化では6項目を大にし、従来の対象範囲を保ち、地点・言語・ツールチップは初期化しません。

初回は**地点を事前設定しません**。国は「指定なし」で、都市・URL・緯度経度は空欄です。選択前は気温をプレースホルダー表示し、天気通信・定期取得を行わず、即時更新は無効です。言語切替や外観初期化で地点を作成しません。地点未選択でも言語・外観を保存できます。

### 検索・適用・保存

1. 基本設定で国または「指定なし」を選びます。
2. 都市・区を入力して検索します。入力だけでは通信しません。
3. 国・行政区・座標を確認して候補を明示的に選び、「地点を適用」を押します。
4. 天気・時区の検証後にプレビューし、保存で確定します。キャンセル・閉じると元に戻り、初回プレビューの取消では未選択に戻って定期取得も停止します。

候補一覧・ヒント・適用ボタンは常設です。リスト内をスクロールでき、有効な候補を選ぶまで適用は無効で、先頭を自動選択しません。状態は矢印のない中央揃えの短い1行で、検索・座標・URLエラーはそれぞれの領域に表示します。任意の完全住所解析ではなく、区の収録状況はサービス次第です。結果がなければ都市名または座標をお試しください。以下の恵城区は文書例であり、ソフトの初期値・入力例ではありません。

### WGS84（GPS）座標とカスタムURL

地点のカスタム設定を開き、座標またはURLを選びます。切替で下書きを消さず、明示的な適用でプレビューします。緯度-90～90、経度-180～180の十進度で、負数・0は有効、欠損は0と扱いません。度分秒は度+分/60+秒/3600へ変換し、南緯・西経は負符号にします。

確認できるWGS84取得方法：[Open-Meteo地点検索ページ](https://open-meteo.com/en/docs/geocoding-api)で都市・国・言語を入力し、生成URLとJSONを確認します。name、country、admin1…admin4を照合し、latitude/longitudeをコピーします。[東京の検索例](https://geocoding-api.open-meteo.com/v1/search?name=Tokyo&countryCode=JP&count=10&language=ja&format=json)も直接確認できます。公式APIと[GeoNames](https://www.geonames.org/about.html)はWGS84と明記しています。機器の説明でWGS84十進度と確認できるGPS出力を使う方法もあります。

WGS84は全球の基準系です。[高徳のGCJ-02説明](https://developer.amap.com/faq/advisory/others/39838)と[百度のBD-09説明](https://lbsyun.baidu.com/docs/jsapi?title=jsapi4/guide/concept/coord)を参照し、未確認で混用しないでください。本ソフトは座標変換ライブラリー/API、地図ピッカー、逆引きを提供しません。Google/Apple地図の全ページでコピーした座標がそのままWGS84とは限らず、具体的なツール・接口を確認してください。

### 公式天気ページからURLを得る

[Open-Meteo天気文書](https://open-meteo.com/en/docs)のLocation and Timeで確認済み緯度経度を入力し、timezoneをautoにします。下記のhourly/daily項目を選び、Settingsで摂氏・m/s・Unix時間を選びます。API ResponseのAPI URLをコピーしてカスタムURLへ貼り、URLを適用して保存します。ページの言語・配置が変わる場合は最終パラメーターを照合してください。

アイコン・毎日気温・今後2日・全ツールチップ項目を含む完全な推奨パラメーター：

```text
hourly=temperature_2m,weather_code,uv_index,wind_direction_10m,wind_speed_10m,relative_humidity_2m,apparent_temperature,precipitation_probability&daily=temperature_2m_max,temperature_2m_min,weather_code,sunrise,sunset&temperature_unit=celsius&wind_speed_unit=ms&timezone=auto&timeformat=unixtime
```

[完全な東京のURL例](https://api.open-meteo.com/v1/forecast?latitude=35.6895&longitude=139.69171&hourly=temperature_2m,weather_code,uv_index,wind_direction_10m,wind_speed_10m,relative_humidity_2m,apparent_temperature,precipitation_probability&daily=temperature_2m_max,temperature_2m_min,weather_code,sunrise,sunset&temperature_unit=celsius&wind_speed_unit=ms&timezone=auto&timeformat=unixtime)は文書例のみで、初期値として適用しません。latitudeとlongitudeを逆にしないでください。

全方式で応答timezone/utc_offset_secondsを確認してから現地日付を解析します。明示的なtimezoneは保持し、欠損・空値だけリクエスト内でautoを補います。重複は最後の空でない値を採用し、元URLや無関係な項目は保持します。未取得は明示し、失敗時は有効なキャッシュを維持、30分・45分偏差にも対応します。応答範囲で固定偏差のため夏時間境界に制限があり、完全対応ではありません。

### 設定・更新・再インストール

設定はプログラム/DLLと同じフォルダーのWeatherBar.xmlです。現行名を優先し、同じフォルダーの旧名だけを互換読み込みします。同フォルダーでアトミック保存します。設定形式5は未選択を表し、旧北京URLを含む有効な既存URL・地点・外観は保持します。破損・新形式の設定は明示して書き込みから保護し、初回とみなして上書きしません。移行バックアップは生成しません。

通常アンインストールはXML/iconsとフォルダーを保持します。同じ保存済みフォルダーへEXEを戻して再インストールすると復元できます。移動はXML/iconsも一緒に行い、EXEだけ別の場所へ置いてもディスクを走査しません。設定やフォルダーの削除、完全削除、Windowsユーザー変更、読み込み不能時は自動復元を保証できません。事前に自分でXML/iconsをコピーできます。リソース展開で既存XMLを空設定に置換せず、外観初期化も地点を変えません。

コンボボックスのホイール保護、今後2日のツールチップ、自動時区は維持します。このアプリについて→データ出典にOpen-Meteo、GeoNames、[CC BY 4.0・出典](https://open-meteo.com/en/licence)があります。アプリのバージョンは1.1です。実行ファイルとチェックサムは[リリースページ](https://github.com/zdxxm10/WeatherBar/releases/tag/v1.1)をご覧ください。

## コピーできるAI向けプロンプト

地点だけ差し替えて使えます。AIは補助で、通信不可・誤答もあるため出典・同名地点・URLを確認してください。

### A：Open-Meteo URL生成

```text
【中国広東省恵州市恵城区】のWGS84十進度座標をオンラインで調査し、同名地点と座標の出典を確認して、WeatherBar用Open-Meteo予報URLを生成してください。
https://api.open-meteo.com/v1/forecast に確認済みlatitude/longitudeと、以下すべてのパラメーターを指定してください：
hourly=temperature_2m,weather_code,uv_index,wind_direction_10m,wind_speed_10m,relative_humidity_2m,apparent_temperature,precipitation_probability&daily=temperature_2m_max,temperature_2m_min,weather_code,sunrise,sunset&temperature_unit=celsius&wind_speed_unit=ms&timezone=auto&timeformat=unixtime
コピーできる完全URL、地点名、緯度・経度を別々に示し、出典リンクを付けてください。座標を作らず、確認不能なら不確実と明記し、GCJ-02/BD-09をWGS84として代用しないでください。
```

```text
【中国広東省恵州市恵城区】内の代表地点のWGS84緯度経度をオンラインで調査し、十進度で緯度・経度を別々に示して、確認可能な出典リンクを付けてください。その座標が都市・区内のどの地点を表すか説明し、行政区の全地点を代表するとは言わないでください。GCJ-02/BD-09を提示せず、座標系不明なら推測せず明記してください。
```
